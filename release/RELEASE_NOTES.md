# CareerPilot AI 0.20.0-rc.1 release notes

This local source release candidate assembles the first individual-job-seeker journey:
profile and evidence, supplied job input, cited analysis/match/gaps, truthful versioned
resume and cover-letter drafts, exact human review, interview learning experience,
application tracking concepts, notifications, audit and privacy controls.

The platform includes bounded LangGraph, Google ADK and OpenAI Agents SDK roles; A2A and
MCP boundaries; Temporal durable workflow; local Pub/Sub semantics; accessible Next.js
workspace; telemetry/evaluation/cost controls; security hardening; Cloud Run IaC, optional
GKE reference and DBOS/Restate comparison labs.

Phase 20 adds scope-aware readiness gates, bounded local load/soak/concurrency, visible
provider-outage and isolated restore checks, SLO/error-budget design, release operations,
complete guides and curriculum.

This candidate is not deployed, published or signed and is `NO-GO` for production until
the blockers in the manifest and go/no-go report are closed. It uses synthetic data and
makes no paid or live-model call by default.
