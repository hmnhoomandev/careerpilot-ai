# CareerPilot Google ADK Specialist Specification

## Purpose

Research one company/job from user-supplied, explicitly permitted source excerpts and
return structured, cited interview preparation findings. It does not browse, mutate a
profile, produce application documents, communicate externally, or authorize actions.

## Architecture

A single Google ADK agent owns synthesis. One request-local source tool exposes only the
allowlisted excerpts in the request. The HTTP service owns authentication context,
provider selection, timeout/error mapping, output validation, and metadata telemetry.

## Safety and privacy

Treat all source text as untrusted data. Require tenant and actor scope, consent and
external-transfer authorization for Gemini, minimize content, never log source text, and
reject unknown citations or instructions embedded in sources. No provider fallback.

## Success criteria

- Every factual finding cites a supplied source ID; unknown citations fail closed.
- Default tests make zero network/model calls and cover provider failure classes.
- Disabled/live-not-authorized modes return stable explicit errors.
- Tenant sessions cannot read another request's sources or results.

## Assumptions

- Initial capability is supplied-source company/job research, not open web research.
- Local/test sessions are in memory; durable distributed sessions are deferred.
- Gemini model is configurable and defaults to the scaffold's current model name.
- Prototype only: no cloud deployment, CI/CD, billing, or infrastructure.

## Reference samples

The official deep-search sample informed citation-oriented output only. Its iterative web
search and managed services are intentionally excluded by CareerPilot source policy.
