# Definition of Done

A phase is complete only when:

- Every in-scope acceptance criterion has recorded evidence.
- Relevant format, lint, type, unit, integration, contract, security, build, and
  documentation checks ran with observed exit status.
- Manual steps have expected and actual-result columns.
- Security, privacy, legal-review, cost, and tenant-isolation impacts are reviewed.
- Schema, API, event, migration, and recovery effects are documented.
- New production behavior has appropriate telemetry and safe logging.
- Requirements traceability links requirement, design, code, and test evidence.
- Documentation, tutorials, annotated source, exercises, and answers are current.
- The complete diff was reviewed for correctness, regressions, drift, and secrets.
- Warnings, skipped checks, mocked behavior, limitations, debt, and risks are clear.
- The phase review contains all mandatory sections.
- The agent stops and waits for the exact next-phase approval command.
