# Phase 17 exercise answers

1. Tags can move; a digest names exact content and makes the deployed artifact reproducible.
2. Numeric non-root users, read-only roots, dropped capabilities, no-new-privileges, bounded tmpfs and network separation reduce impact.
3. Migration changes durable shared state; traffic shift changes compute revisions and is cheaply reversible. Coupling them hides recovery choices.
4. Record service unavailability, chosen region, residency, security/privacy, latency and cost implications, then obtain approval before changing configuration.
