# CareerPilot engineering curriculum

Study phases 0–20 in order. Each tutorial pairs with exercises and separate answers under
`docs/exercises/`. The sequence moves from product/architecture and developer foundations,
through identity/data/RAG/tools/agents/approvals/interoperability/durable execution/UI,
into observability/security/deployment/comparison and release readiness.

Recommended practice:

1. Read the phase ADR, architecture note and annotated source.
2. Run the focused safe tests with synthetic data.
3. Complete exercises without opening answers.
4. Explain the phase's ownership and trust boundaries aloud.
5. Inspect the phase review for limitations and evidence quality.
6. Finish with `CAPSTONE.md`, then compare `CAPSTONE_ANSWERS.md`.

The curriculum teaches production reasoning, not vendor collection: distinguish agentic
decisions from deterministic policy, graph from workflow state, tools from agents, retry
from fallback, authentication from authorization, and test evidence from operational proof.
