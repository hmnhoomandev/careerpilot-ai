# ADR-0006: Next.js App Router Web Interface

- **Status:** Accepted
- **Date:** 2026-08-09

## Decision

Use Next.js, React, TypeScript, and the App Router for an accessible web product.
English is initial, but routing, messages, dates, numbers, and schemas must avoid
hard-coded locale assumptions. Accessibility targets WCAG 2.2 AA-oriented tests.

## Consequences

Phase 1 establishes the shell only; Phase 14 completes product screens. Domain
contracts contain stable codes rather than English presentation text.
